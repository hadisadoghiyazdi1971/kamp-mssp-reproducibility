# KAMP: Reproducibility Package for Covariance-Aware Sparse Recovery

**Repository:** https://github.com/hadisadoghiyazdi1971/kamp-mssp-reproducibility  
**Repository description:** Reference implementation, generated benchmark data, experiment drivers, figures, and reproducibility materials for Kalman Approximate Message Passing (KAMP).

## Manuscript
**KAMP: Kalman Approximate Message Passing for Covariance-Aware Sparse Recovery with Explicit Uncertainty Quantification**  
Yousof Ghalenoei and Hadi Sadoghi-Yazdi.

## What this repository contains
This repository is a research-facing reproducibility package for KAMP and is intended to remain useful independently of any particular journal submission. It includes the KAMP/baseline implementation, the experiment driver, manuscript-aligned CSV outputs, the manuscript figures, and documentation that maps each reported claim to an experiment and data file.

The shared development code also contains DKAMP utilities. DKAMP is **not** one of the six solver implementations compared in this manuscript. The paper-facing result files remove DKAMP rows, and `experiments/reproduce_paper.py` exposes only manuscript experiments R01-R15. In the legacy development suite, the channel experiment is numbered R17; the wrapper maps it to manuscript R15.

## Quick start
```bash
python -m venv .venv
# Windows: .venv\Scripts\activate
# Linux/macOS: source .venv/bin/activate
python -m pip install -r requirements.txt
python experiments/reproduce_paper.py --only R01 R03 --fast
```
Run the complete (non-fast) study with:
```bash
python experiments/reproduce_paper.py
```

## Data status
All numerical datasets used by the manuscript are generated by simulation; no human-participant or proprietary dataset is required. Processed manuscript-facing CSV files are in `results/paper_data/`. They preserve the supplied numerical values while restricting solver-comparison tables to the six methods actually reported in the paper. The six-solver Holm correction for R03 is recomputed from the supplied raw pairwise p-values.

## Important reproducibility boundary
The supplied development pipeline generates Gaussian sensing matrices with entries scaled by `1/sqrt(n)`. Classical AMP analyses often use a `1/sqrt(m)` convention. Because changing this convention would require regenerating the full benchmark, this repository preserves the submitted experiment generator and flags the issue in `docs/REPRODUCIBILITY_AUDIT.md`. Users should not interpret the large AMP errors as a theoretical impossibility result for the AMP family.
